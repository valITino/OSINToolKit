# Reverse image

Find where an image (or a face) appears elsewhere online.

<!-- BEGIN:TOOLS -->
| Tool | Answers | Tier | Contact |
|---|---|---|---|
| [Google Lens](google-lens.md) | What is actually **in** this photo - the building, the sign, the product - and where else does this scene appear? | 2 | passive |
| [TinEye](tineye.md) | Where did this exact image first appear, and how has it been used and modified since? | 2 | passive |
| [Yandex Images](yandex-images.md) | I have a photo. Where else does this image - or a visually similar one, or this person's face - appear online? | 2 | passive |
| [EagleEye](eagleeye.md) | Given a name and some photos, can automated face comparison find that person's social media profiles? | 3 | active |
