# Cheatsheets

Tool files are capped at ~80 lines so they stay scannable. When a tool genuinely
needs more - a long flag reference, a multi-step recipe, a decoding table - it
gets a cheatsheet here and the tool file links to it.

## Index

_No cheatsheets yet._ Add one as `topic-name.md` and link to it from the relevant
tool file's Gotchas or Usage section.

## What belongs here

- Extended flag references that would bloat a tool file.
- Cross-tool recipes (e.g. "CT logs to live hosts to screenshots" as one pipeline).
- Decoding/lookup tables (email header fields, common ports, PDF object types).

## What does not

- Anything that duplicates a tool file - link, do not copy.
- Exploit or payload content - out of scope (see [../../LEGAL.md](../../LEGAL.md)).
- Vendored third-party material - link to the source instead.
