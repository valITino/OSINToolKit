# Awesome lists

This repo is opinionated and tiered on purpose. When you need the exhaustive dump
instead - every tool in a niche, kept current by a community - these are the lists
to reach for. They are the complement to this repo, not a substitute for its
"what question does it answer?" framing.

| List | Scope |
|---|---|
| [OSINT Framework](https://osintframework.com/) | Browsable tree of OSINT resources by data type |
| [awesome-osint](https://github.com/jivoi/awesome-osint) | Large curated OSINT tool and source list |
| [awesome-bugbounty-tools](https://github.com/vavkamil/awesome-bugbounty-tools) | Recon and web-testing tooling, bug-bounty flavoured |
| [Kali Tools](https://www.kali.org/tools/) | Reference for every packaged Kali tool |
| [Bellingcat's Online Investigation Toolkit](https://bellingcat.gitbook.io/toolkit) | Investigator-facing, strong on verification and geolocation |
| [Awesome Threat Intelligence](https://github.com/hslatman/awesome-threat-intelligence) | Feeds, platforms, and TI resources |

## How to use them with this repo

- Use these to **discover** a candidate tool, then write it up here with a tier and
  contact level so the next person knows whether it is worth their time and whether
  it is safe to run.
- A tool being on an awesome-list is not evidence it still works. Check its repo
  activity and set `status` honestly - half the value of this repo is saying which
  of these are dead.
