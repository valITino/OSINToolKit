# OSINT Tools for the Dark Web

## What question does it answer?
I need to discover candidate tools for searching, finding, scanning, or crawling
onion services. Which projects and services should I evaluate next?

## Why this is tier 3
This is a short link collection, not an investigative tool. It is useful as a
discovery checklist, but it does not assess contact level, maintenance, safety,
or fitness for a case. Several entries already have fuller, deduplicated records
in this toolkit; follow those records rather than treating inclusion in the list
as a recommendation.

## Output
A categorized set of links covering dark-web search engines, onion-link sources,
scanners, crawlers, and miscellaneous projects. It supplies names and URLs, not
results from the dark web or a comparative evaluation.

## Gotchas
- Many entries connect to onion services or actively scan or crawl them. The
  collection does not label that boundary; determine contact level before use.
- A listed project is not necessarily current or safe. Review its repository,
  dependencies, address-version support, and recent activity independently.
- The list overlaps this toolkit's entries for Ahmia, OnionSearch, darkdump,
  OnionScan, docker-onion-nmap, and TorBot. Those are not additional tools here.
- Some links lead directly to third-party services, including onion addresses.
  Do not open them outside the isolation described in
  [dark-web access and OPSEC](../../12-darkweb/access-and-opsec/README.md).
